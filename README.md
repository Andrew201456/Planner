# Planner

Ελληνικό σημειωματάριο για κινητό με χρωματιστά τετράδια, λίστες και μηνιαίο ημερολόγιο. Οι σημειώσεις αποθηκεύονται στον browser της συσκευής. Η εφαρμογή λειτουργεί χωρίς λογαριασμό ή βάση δεδομένων.

## Τοπική εκτέλεση

Από τη ρίζα του repository εκτέλεσε την εντολή και άνοιξε το `http://localhost:8000`.

```sh
python -m http.server 8000 --directory dist
```

## Cloudflare Workers

Ο φάκελος `dist/` περιέχει την έτοιμη εφαρμογή. Το `wrangler.jsonc` τον δηλώνει ως φάκελο στατικών αρχείων. Για δημοσίευση από συνδεδεμένο λογαριασμό Cloudflare εκτέλεσε `npx wrangler deploy` από τη ρίζα του repository.
